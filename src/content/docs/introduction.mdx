# Introduction

What AgentGate is and what it is not.

AgentGate is a **framework-agnostic Python guardrail engine** for AI agent tool
actions. It evaluates proposed actions before they are executed through APIs,
browsers, files, or external systems.

<DocCallout>
  **Important:** AgentGate is not a regular chatbot and it is not a browser
  extension in the MVP. Its focus is a pre-action guardrail for tool actions.
</DocCallout>

The system supports API-based actions such as Gmail, Google Calendar, GitHub,
and Stripe Sandbox, as well as Playwright-based browser actions such as open,
snapshot, click, type, select, submit, and screenshot.
