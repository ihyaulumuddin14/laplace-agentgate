The MVP is console-first: one web demo that makes the guardrail observable.

The goal is not breadth of integrations. It is to prove that a pre-action
guardrail can evaluate real tool actions, return a decision fast enough to sit
in the hot path, and leave an audit trail a reviewer can trust.

<DocCallout>
  **Console-first.** The Demo Console is the product surface of the MVP. The
  browser extension, MCP adapter, and LangGraph adapter are explicitly post-MVP.
</DocCallout>

## Frontend scope

This repository covers the public website, the documentation, and the Demo
Console. It consumes only `ActionRequest` and `DecisionResponse` from the
backend and holds no evaluation logic of its own.

| Surface | Contents |
| --- | --- |
| Landing Page | Risk framing, flow, decisions, scenarios, roadmap |
| Documentation | Native MDX pages under `src/content/docs` |
| Demo Console | Scenario tab, State View, Logs |

## Owned by the DS and DE teams

The evaluation engine itself lives outside this repository:

- AgentGate Core
- LLM Planner
- Policy Engine
- Risk Scoring
- Playwright Executor
- API Connectors
- Browser Extension
- MCP and LangGraph adapters

## Working assumptions

- Sessions are ephemeral. A session is created on entering the Demo Console and
  ended on reset, refresh, or page hide — there is no durable user account.
- Mock data is used while a backend endpoint is unavailable, so frontend and
  backend work can proceed in parallel.
- Stripe actions run against the sandbox only. No live payment is ever executed.
